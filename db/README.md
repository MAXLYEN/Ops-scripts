# 数据库维护

本目录处理数据库密码轮换，以及应用 SQLite 中保存的连接串。两支脚本都读取本机配置并需要数据库相关工具；写入操作前先确认备份与下游连接方式。

| 文件 | 版本 | 作用 |
| --- | --- | --- |
| `rotate-db-pass.sh` | 2.0.5 | 轮换数据库密码并核对所有 host 记录 |
| `sqlite-dsn.sh` | 2.0.1 | 扫描和修改 SQLite 中保存的数据库连接串 |

## 操作入口

- `rotate-db-pass.sh check <用户名>` 只读核对同一账号的各条 host 记录；轮换前后各跑一次。同名账号可能对应多个 host，需确认密码哈希一致；新密码用字母数字，避免连接串分隔符引起解析问题。
- `rotate-db-pass.sh rotate <用户名> [下游sqlite] [容器名]` 轮换密码并处理下游连接串。
- `sqlite-dsn.sh scan <db文件> [特征串...]` 只读扫描并掩码显示密码。
- `sqlite-dsn.sh sethost <db文件> <旧值> <新值> [容器名]` 和 `setpass` 会修改 SQLite。数据库有 WAL 时应停止相关容器，避免并发写入。迁移到 NAT 机器时，检查库内是否仍有指向旧机器公网 IP 的 DSN；容器未必能经公网地址访问本机数据库。

脚本帮助已改为显式输出，不再依赖头注释的固定行号。版本记录见 [CHANGELOG.md](CHANGELOG.md)。
